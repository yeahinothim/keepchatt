# Changelog

## 1.5v
- **New Command:** `/clearhistory` - Clears all messages in the current channel (Moderator only).
- **New Command:** `/purge <number>` - Removes a specific number of previous messages (Moderator only).
- **Random Improvements:** 
    - Added a subtle "message count" indicator in channel headers.
    - Improved command response handling speed.
    - Added minor UI tweaks for better moderation feedback.
